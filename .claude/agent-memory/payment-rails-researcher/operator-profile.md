# Operator profile

MoneyMatch's operator is a **solo developer resident in Canada**, and **Canada (Ontario first) is the intended launch market** — not the US. This shapes every jurisdiction recommendation: prefer Canadian provincial routes, weigh personal criminal-liability exposure heavily, and treat the US as a later/secondary market with a worse risk profile for a solo Canadian.

App = React + Express/SQLite, betting on fighting-game tournaments. Two products, currently play-money: **Futures** (outright winner, seed-based fixed odds, 5% baked margin, house is counterparty) and **Live** (in-play parimutuel on Top 8 sets, ~5% rake, house carries no outcome risk).
